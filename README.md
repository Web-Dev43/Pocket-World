# Pocket World — Prototype 1

This is the first playable foundation test for Pocket World.

## Run it

1. Open the repository's GitHub Pages URL after Pages is enabled for the `main` branch and `/(root)`.
2. Open it in Safari on iPhone.
3. Use the on-screen joystick to walk.
4. Drag on the right side of the screen to look around.
5. On desktop, use WASD or the arrow keys.

The prototype uses Babylon.js from its official CDN and does not require a build step or API key.

## Prototype scope

- Small flat test platform
- Simple third-person character
- Touch joystick and camera-look gesture
- Keyboard movement for desktop testing
- Basic platform boundary limits

This is a movement test only. It does not yet include saving, NPCs, physics-based collision, or the full Pocket World simulation.
